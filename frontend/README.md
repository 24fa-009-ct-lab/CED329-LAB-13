# Full Stack To-Do Application

## Project Description
This project is a Full Stack To-Do List Application
using React.js and Express.js.

## Technologies Used
- React.js
- Node.js
- Express.js
- Axios
- CSS

## Features
- View all tasks
- Add new tasks
- Prevent duplicate tasks
- Mark tasks as completed
- Delete tasks

## Backend
Express server runs on port 5000.

## Frontend
React application runs on port 3000.

## Installation

Backend:
npm install
node server.js

Frontend:
npm install
npm start
